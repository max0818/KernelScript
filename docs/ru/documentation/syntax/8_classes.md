## Классы

## Объявление класса
```ks
class название {
	код
}
```

## Поле
```ks
# Обычное
название = значение

# Приватное
private название = значение

# Статическое
static название = значение

# Приватное и статическое
private static название = значение
```

## Конструктор
```ks
# Не может быть приватным и статическим

init(аргументы) {
	код
}
```

## Метод
```ks
# Обычный
название(аргументы) {
	код
}

# Статический
static название(аргументы) {
	код
}

# Приватный
private название(аргументы) {
	код
}

# Приватный и статический
private static название(аргументы) {
	код
}
```

## Создание экземпляра
```ks
new класс(аргументы)
```
