## Функции

## Обычные функции

### Синтаксис
```ks
# При указании типа возврата, добавить return необходимо

fn название(аргументы): тип {
	код
	return значение
}
```

## Короткая функция

### Синтаксис
```ks
var название: function = fn(аргументы): тип {
	код
	return значение
}
```

## Вызов функции

### Синтаксис
```ks
название(аргументы)
```

## Вызов функции с возвратом

### Синтаксис
```ks
var переменная: function = функция(аргументы)
```
