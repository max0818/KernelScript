## Примеры

### Увеличение всех значений на 2 в массиве
```ks
flag Console # Флаг для работы с консолью
flag Array # Флаг для работы с массивами

# Тестовый массив
var test: array<int> = [1, 2, 3, 4, 5, 6, 7, 8, 9]

# Счётчик
var i = 0

# Создаём цикл
while (i < test.size) {
	test[i] += 2 # Увеличиваем на 2

	print(test[i]) # Выводим обновлённое значение в консоль

	++i # Увеличиваем счётчик на 1
}

/*
Вывод в консоль:
3
4
5
6
7
8
9
10
11

*/
```
