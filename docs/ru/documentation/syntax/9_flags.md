## Флаги

- Все флаги всегда должны быть в начале кода

### Typing

Что требуется после добавления флага:
- Указывать тип объявляемым переменным `var x: int`
- Указывать тип объявляемым константам `const y: int = 1`
- Указывать тип параметрам функций и методов `fn add(a: int)`
- Указывать тип возврата функциям `fn add(): int {}`
- Указывать вложенные типы в составных типах `array<int, float>`
- Нельзя использовать тип `any`
