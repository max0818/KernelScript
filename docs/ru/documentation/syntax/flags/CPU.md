## CPU

- Доступен только на низком уровне

### Добавляет методы для работы с процессором напрямую

|**Метод**|**Описание**|
|-|-|
|`info(): object<any>`|Информация о процессоре|
|`thread(): object<any>`|Работа с потоком|
|`core(): object<any>`|Работа с ядром|
|`free(): bool`|Очистка потока|
|`call(address: int)`|Вызов прерывания|
|`asm(code: string): bool`|Ассемблерная вставка|
