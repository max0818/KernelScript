## Object

### Добавляет методы для работы с объектами

|**Метод**|**Описание**|
|-|-|
|||
|**Получение**||
|`getKeys(): array<string>`|Получить все ключи объекта|
|`getValues(): array<any>`|Получить все свойства объекта|
|`getAll(): array<array>`|Получить все поля объекта|
|||
|**Изменение**||
|`delete(key): bool`|Удалить поле по ключу в объекте|
|`freeze(): bool`|Сделать объект неизменяемым|
|||
|**Разное**||
|`copy(): object`|Полностью скопировать объект|
|`in(key): bool`|Содержит ли объект поле по данному ключу|
|`size: int`|Количество полей в объекте|
|||
