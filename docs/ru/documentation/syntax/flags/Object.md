## Object

### Добавляет методы для работы с объектами

|**Метод**|**Описание**|
|-|-|
|||
|**Получение**||
|`getKeys()`|Получить все ключи объекта|
|`getValues()`|Получить все свойства объекта|
|`getAll()`|Получить все поля объекта|
|||
|**Изменение**||
|`delete(key)`|Удалить поле по ключу в объекте|
|`freeze()`|Сделать объект неизменяемым|
|||
|**Разное**||
|`copy()`|Полностью скопировать объект|
|`in(key)`|Содержит ли объект поле по данному ключу|
|`size`|Количество полей в объекте|
|||
