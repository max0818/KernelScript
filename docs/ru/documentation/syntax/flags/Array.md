## Array

### Добавляет методы для работы с массивами

|**Метод**|**Описание**|
|-|-|
|||
|**Поиск**||
|`includes(variant: any): bool`|Содержит ли массив значение|
|`indexOf(variant: any, startPos: int): int`|Получить индекс значения с *начала* массива|
|`lastIndexOf(variant: any, startPos: int): int`|Получить индекс значения с *конца* массива|
|||
|**Изменение**||
|`push(...variant: any): bool`|Добавить значения в *конец* массива|
|`pop(): bool`|Удалить *последнее* значение массива|
|`delete(index: int): bool`|Удалить значение массива по *индексу*|
|`sort()`|Сортировка массива|
|`forEach(function: function<any>)`|Прохождение по всем значениям массива|
|||
|**Разное**||
|`copy(): array<any>`|Полностью скопировать массив|
|`typeOfArray(): string`|Определённый тип значений в массиве|
|`size: int`|Длина массива|
|||
