## Array

### Добавляет методы для работы с массивами

|**Метод**|**Описание**|
|-|-|
|||
|**Поиск**||
|`includes(variant: any)`|Содержит ли массив значение|
|`indexOf(variant: any, startPos: int)`|Получить индекс значения с *начала* массива|
|`lastIndexOf(variant: any, startPos: int)`|Получить индекс значения с *конца* массива|
|||
|**Сортировка**||
|`sort()`|Сортировка массива|
|`forEach(function: function<any>)`|Прохождение по всем значениям массива|
|||
|**Изменение**||
|`push(...variant: any)`|Добавить значения в *конец* массива|
|`pop()`|Удалить *последнее* значение массива|
|`delete(index: int)`|Удалить значение массива по *индексу*|
|||
|**Разное**||
|`copy()`|Полностью скопировать массив|
|`typeOfArray()`|Определённый тип значений в массиве|
|`size`|Длина массива|
|||
