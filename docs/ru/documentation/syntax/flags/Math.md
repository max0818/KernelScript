## Math

### Добавляет методы и константы для арифметики и расчётов

**Константы:**
- `PI` - Число π
- `E` - Число Эйлера

|**Метод**|**Описание**|
|-|-|
|||
|**Округление**||
|`ceil(number: float)`|Округление вверх `1.2 -> 2`|
|`round(number: float)`|Умное округление `1.2 -> 1` `1.8 -> 2`|
|`floor(number: float)`|Округление вниз `1.8 -> 1`|
|||
|**Преобразование**||
|`toInt(variant: any)`|Преобразовать в `int`|
|`toFloat(variant: any)`|Преобразовать в `float`|
|||
|**Разное**||
|`random()`|Случайное число от 0 до 1|
|`min(...numbers: float)`|Минимальное число|
|`max(...numbers: float)`|Максимальное число|
|||
