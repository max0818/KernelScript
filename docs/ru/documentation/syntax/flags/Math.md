## Math

### Добавляет методы и константы для арифметики и расчётов

**Константы:**
- `PI: float` - Число π
- `E: float` - Число Эйлера

|**Метод**|**Описание**|
|-|-|
|||
|**Округление**||
|`ceil(number: float): float`|Округление вверх `1.2 -> 2`|
|`round(number: float): float`|Умное округление `1.2 -> 1` `1.8 -> 2`|
|`floor(number: float): float`|Округление вниз `1.8 -> 1`|
|||
|**Извлечение корня**||
|`sqrt(number: float): float`|Извлечь *квадратный* корень|
|`cbrt(number: float): float`|Извлечь *кубический* корень|
|||
|**Преобразование**||
|`toInt(variant: any): int`|Преобразовать в `int`|
|`toFloat(variant: any): float`|Преобразовать в `float`|
|||
|**Разное**||
|`random(): float`|Случайное число от 0 до 1|
|`min(...numbers: float): float`|Минимальное число|
|`max(...numbers: float): float`|Максимальное число|
|||
