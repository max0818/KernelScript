## Переменные

|Тип|Описание|
|-|-|
|`var`|Создание переменной|
|`const`|Создание константы|

## Синтаксис

### Переменная
```ks
var название: тип = значение
```

### Константа
```ks
const название: тип = значение
```

## Примеры

### Переменная без типа и значения
```ks
var x
```

### Переменная с типом, но без значения
```ks
var x: int
```

### Переменная без типа, но с значением
```ks
var x = 67
```

### Переменная с типом и значением
```ks
var x: int = 67
```

### Константа без типа, но с значением
```ks
const PI = 3.14
```

### Переменная с типом и значением
```ks
const PI: float = 3.14
```
