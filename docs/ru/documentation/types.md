## Типы

- `int` в `float` - расширение допустимо

|Тип|Описание|
|-|-|
|||
|Автоопределение||
|`any`|Неопределённый|
|||
|Простые||
|`bool`|Логический|
|`int`|Целочисленный|
|`float`|Дробный|
|`string`|Строка|
|||
|Составные||
|`array`|Массив|
|`array<T>`|Массив с определёнными типами значений|
|`object`|Объект|
|`object<T>`|Объект с определёнными типами значений полей|
|||
|Структуры||
|`function`|Функция|
|`function<T>`|Функция с определённым типом возврата|
|||

### Составные типы
```ks
# Неправильно

# Нельзя делать вложенные составные типы:
array<array<int>>

# Нельзя для возврата прописывать несколько типов:
function<int, string>

# Нельзя оставлять тип пустым:
object<>


# Правильно:

array<int, float, bool, array>

function<string>

object
```
