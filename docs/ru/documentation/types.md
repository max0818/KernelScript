## Типы

|Тип|Описание|
|-|-|
|`any`|Неопределённый|
|-|-|
|`bool`|Логический|
|-|-|
|`int`|Целочисленный|
|`float`|Дробный|
|-|-|
|`string`|Строка|
|-|-|
|`array`|Массив|
|`array<T>`|Массив с определённым типом значений|
|`object`|Объект|
|`object<T>`|Объект с определённым типом значений в полей|
|-|-|
|`function`|Функция|
|`function<T>`|Функция с определённым типом возврата|

- `int` в `float` - расширение допустимо
