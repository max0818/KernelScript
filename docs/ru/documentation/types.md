## Типы

- `int` в `float` - расширение допустимо

|Тип|Описание|
|-|-|
|||
|Автоопределение||
|`any`|Неопределённый|
|||
|Простые||
|`bool`|Логический|
|`int`|Целочисленный|
|`float`|Дробный|
|`string`|Строка|
|||
|Составные||
|`array`|Массив|
|`array<T>`|Массив с определённым типом значений|
|`object`|Объект|
|`object<T>`|Объект с определённым типом значений полей|
|||
|Структуры||
|`function`|Функция|
|`function<T>`|Функция с определённым типом возврата|
|||
